Gobernar el lenguaje visual, las superficies Mobile/Web y las fichas de pantalla.

## Principios

- Claridad por encima de ornamentación.
- Acción crítica distinguible y confirmación observable.
- Accesibilidad por teclado, lector, contraste y tamaño.
- Los cuatro idiomas reciben el mismo comportamiento funcional.
- Error y estado vacío ayudan a recuperar la tarea.

## Fuera de alcance

- Reglas Backend.
- Persistencia Database.
- Tokens de diseño no verificados.
- Pantallas sin requisito o historia.

## Listo cuando

- Componentes, estados y textos son consistentes.
- Mobile y Web declaran sus diferencias.
- Los cuatro idiomas y accesibilidad se prueban.
- Cada pantalla crítica tiene trazabilidad.

# 01 — Contexto

> [!NOTE] INSTRUCTIONS
> Esta sección se completa antes del dominio. Mantenga el bloque hasta validar actores, problema, alcance y vocabulario con responsables funcionales.

## Propósito

Explica qué es AlertaMujer, quién lo usa, qué problema atiende, cuáles son sus restricciones y dónde termina su responsabilidad.

## Fuera de alcance

- Describir rutas API, tablas, carpetas o comandos de desarrollo.
- Enumerar historias de usuario o criterios de aceptación.
- Presentar arquitectura objetivo como estado implementado.
- Resolver decisiones pendientes de producto u operación.

## Listo cuando

- [ ] Usuaria, administrador, contacto, visitante y servicios externos están definidos.
- [ ] El problema y los límites no prometen respuesta institucional garantizada.
- [ ] Alcance y exclusiones enlazan requisitos verificables.
- [ ] El glosario elimina sinónimos ambiguos entre documentos.
- [ ] Una segunda persona revisó contexto contra la fuente funcional vigente.

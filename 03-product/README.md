# 03 — Producto

> [!NOTE] INSTRUCTIONS
> Esta sección expresa problema, visión y recorrido; no debe convertirse en catálogo técnico.

## Propósito

Declara por qué vale la pena construir AlertaMujer, qué resultados persigue y cómo avanza una persona por el flujo principal.

## Documentos

| Documento | Responde | Prioridad |
|---|---|---|
| [problem-framing.md](./problem-framing.md) | ¿Qué problema existe y cuál es el costo de no atenderlo? | ⭐ |
| [vision.md](./vision.md) | ¿Qué resultado futuro guía las decisiones? | ⭐ |
| [functional-flow.md](./functional-flow.md) | ¿Cómo funciona el recorrido principal de extremo a extremo? | ⭐ |

## Fuera de alcance

- Definir tablas, endpoints, frameworks o estructura de carpetas.
- Describir historias con criterios de aceptación completos.
- Prometer disponibilidad, entrega o respuesta externa no comprobada.
- Confundir objetivo de producto con estado implementado.

## Listo cuando

- [ ] El problema identifica actor, situación y consecuencia.
- [ ] La visión se puede evaluar con resultados, no características vagas.
- [ ] El flujo respeta reglas de dominio y límites de actores.
- [ ] Cada objetivo conduce a requisitos verificables.
- [ ] Alcance fue revisado en la puerta de descubrimiento.

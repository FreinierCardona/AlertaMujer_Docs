## Fuera de alcance

- Decidir frameworks, tablas, endpoints o layouts de pantalla.
- Declarar una historia implementada sin evidencia del repositorio responsable.
- Crear requisitos para justificar código ya escrito.
- Usar criterios vagos como “rápido”, “seguro” o “amigable” sin condición observable.

## Listo cuando

- [ ] Cada RF/RNF tiene dueño, historias y evidencia esperada.
- [ ] Cada HU satisface Definition of Ready antes de iniciar.
- [ ] Las dependencias entre ecosistemas están identificadas.
- [ ] Los vacíos cuantitativos permanecen `En refinamiento`.
- [ ] No existen identificadores duplicados o reutilizados.

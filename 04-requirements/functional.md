# 04 — Requisitos Funcionales

> [!NOTE] INSTRUCTIONS
> Los identificadores son estables. No renumere requisitos al retirar uno; actualice historias, contratos y trazabilidad.

## Requisitos

| Id | Capacidad | Actor | Resultado verificable |
|---|---|---|---|
| RF1 | Identidad y acceso | Usuaria / administrador | Registro, verificación, sesión y recuperación controlados. |
| RF2 | Contactos | Usuaria | Invitar, aceptar, rechazar y consultar relaciones válidas. |
| RF3 | Mensaje de ayuda | Usuaria | Configurar texto y copiarlo al crear emergencia. |
| RF4 | Ubicación | Usuaria | Capturar y compartir coordenadas confirmadas durante alerta. |
| RF5 | SOS | Usuaria | Crear una única emergencia abierta y seguir su estado. |
| RF6 | Marcador | Usuaria | Abrir marcador Android sin llamada automática. |
| RF8 | Evidencia | Usuaria / administrador | Capturar y consultar fotografías autorizadas. |
| RF9 | Historial | Usuaria | Consultar emergencias finalizadas y datos asociados. |
| RF10 | Notificaciones | Contacto | Registrar un intento FCM por contacto elegible. |
| RF11 | Acceso administrativo | Administrador | Autenticarse y acceder solo con rol vigente. |
| RF12 | Gestión de usuarias | Administrador | Consultar y ejecutar cambios autorizados sobre cuentas. |
| RF13 | Monitoreo y atención | Administrador | Listar alertas, ver detalle e iniciar atención. |
| RF14 | Auditoría y reporte | Administrador | Consultar eventos y resúmenes sin editarlos. |
| RF15 | Web pública y APK | Visitante | Conocer capacidades y disponibilidad real del artefacto. |
| RF16 | Chat | Usuaria / administrador | Intercambiar mensajes dentro de una emergencia autorizada. |
| RF17 | Perfil | Usuaria | Consultar y editar campos permitidos. |
| RF18 | Idioma | Todos | Usar español, inglés, portugués o francés sin perder contexto. |
| RF19 | Apariencia | Todos | Usar modo claro u oscuro con jerarquía legible. |

## Interpretación

Un requisito vigente define alcance, no implementación. Consulte el catálogo de historias y el módulo responsable para conocer el estado real.
